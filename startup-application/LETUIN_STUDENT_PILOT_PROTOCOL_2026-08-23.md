# 렛유인 특강 참여자 대상 Virtual Fab 파일럿 프로토콜

작성일: 2026-08-23  
상태: 렛유인 담당자 승인 전 초안  
목적: 산업동향·현업 용어·SCM·기업정보 수요와 가상팹 사용성·판단 행동을 소규모로 검증

## 1. 운영 원칙

1. 렛유인 담당자의 사전 승인을 받은 뒤 렛유인 채널에서 자율 참여자를 모집한다.
2. 과거 특강 참여자의 연락처를 별도로 받거나 임의로 직접 연락하지 않는다.
3. 이름·이메일·전화번호·학교·회사·학번을 수집하지 않는다.
4. 참여코드는 브라우저에서 무작위로 만들고 사전·사후 응답 연결에만 사용한다.
5. 실제 회사 데이터·Recipe·Spec·로그·개인정보를 입력하지 않는다.
6. 개인 AI API 키 입력은 필수가 아니다. 웹 AI 복사·붙여넣기 방식으로도 참여할 수 있다.
7. 연구·홍보 인용은 집계값과 익명 의견만 사용하며, 철회를 요청할 수 있게 한다.
8. 파일럿은 채용 합격이나 실제 공정 역량을 보장하지 않는다.

## 2. 검증 질문

- 학생은 별도 설치 없이 대표 시나리오를 완주할 수 있는가.
- 학생이 가장 부족하다고 느끼는 정보는 산업동향·현업 용어·SCM·기업정보·공정실습 중 무엇인가.
- 학생은 기업이 SCM에서 맡는 역할과 공정 문제의 영향을 연결할 수 있는가.
- 학생은 출처·기준일을 찾고 `공식 확인`과 `추론`을 구분할 수 있는가.
- 학생은 평균값보다 Tool·Lot·위치 분포와 데이터 품질을 먼저 확인하는가.
- 학생은 AI 답을 그대로 채택하지 않고 수정·기각 근거를 남기는가.
- 제한된 예산과 시간에서 필요한 분석 영역을 충족하는가.
- 학생과 교육담당자는 이 경험을 기존 강의의 어떤 공백을 채우는 것으로 보는가.
- 교육과정에 다시 포함할 가치와 지불의향이 있는가.

## 3. 대상과 규모

- 1차: 렛유인 AI 특강 참여자 중 자율 신청 5–10명
- 권장 환경: PC 또는 노트북 Chrome 최신 버전
- 코딩 경험: 제한 없음
- 반도체 지식: 입문–중급 혼합
- 파일럿 시간: 70분

표본이 작으므로 통계적 일반화보다 오류 발견·행동 관찰·문제 인터뷰를 우선한다.

## 4. 진행 순서

### 0–5분 · 안내와 동의

- 파일럿 목적과 합성 데이터 고지
- 익명 참여코드 생성
- 실제 회사정보 입력 금지 안내
- 중단·철회 가능 안내

### 5–15분 · 니즈 조사와 사전 진단

아래 문항을 AI 없이 답한다. 각 문항은 정답보다 선택 근거를 함께 기록한다.

1. 반도체 취업 준비에서 가장 부족한 정보를 산업동향·현업 용어·SCM 생태계·기업정보·공정실습 순으로 정렬한다.
2. 관심 기업 하나가 고객·Fab·장비·재료·설계·OSAT 중 어디에 속하는지와 근거를 적는다.
3. 평균 CD는 규격 안이지만 wafer edge 산포가 증가했다. 후속 공정을 진행할지, 무엇을 먼저 확인할지 적는다.
4. Tool 평균이 가장 높은 장비와 edge 저하가 가장 큰 장비가 다를 때 원인 장비를 어떻게 좁힐지 적는다.
5. 결측·단위오류·중복이 있는 CSV의 분석 순서를 적는다.
6. 경쟁 가설 2개를 구분할 대조군과 판정 기준을 적는다.

### 15–25분 · Industry Twin 개념검증

- 최신 산업지표 카드 1개에서 기준일·출처·단위 찾기
- 현업 용어 5개를 공정·장비·재료·직무와 연결하기
- 관심 기업 3개를 SCM 지도에 배치하고 공식 근거 열기
- 공시로 확인된 관계와 제품군 기반 추론을 구분하기
- 가장 자주 다시 보고 싶은 정보와 불필요한 정보를 선택하기

초기에는 완전한 실시간 서비스라고 주장하지 않고 클릭형 카드 또는 검증된 데이터 스냅샷을 사용한다.

### 25–60분 · 대표 PHOTO 시나리오

- 접속: <https://waterfirst.pro/virtual-fab/#photo-cd-drift>
- 사건 판단
- 서버 CSV 미리보기
- Tool·Lot·`radius_mm` bin·slot·시간 집계
- AI와 8회 문답 또는 외부 웹 AI 답변 붙여넣기
- 회차별 채택·수정·기각과 검증 근거 기록
- Industry Twin에서 확인한 용어·기업 역할·산업맥락을 가설에 1회 이상 연결
- DOE와 분석도구 선택
- Holdout 확인
- 역량 증거 리포트와 최종 기록 내려받기

진행자는 정답을 알려주지 않고 막힌 시각과 질문만 기록한다.

### 60–70분 · 사후 진단과 설문

사전 문항과 같은 역량을 묻되 수치·Tool·Lot을 바꾼 동형 문항을 사용한다. 문구를 그대로 반복하지 않는다.

- 가장 먼저 확인할 증거
- 평균과 공간분포가 충돌할 때의 판단
- 데이터 품질 감사 순서
- 경쟁 가설과 반증 실험
- 분석비용과 정보가치의 균형
- 기업의 SCM 역할과 공정 사건의 영향 연결
- 정보의 출처·기준일·신뢰등급 구분

## 5. 공통 채점 rubric

각 사전·사후 응답을 0–2점으로 채점한다. 총 14점이다.

| 영역 | 0점 | 1점 | 2점 |
|---|---|---|---|
| 이상 대응 | 평균만 보고 진행 | 보류하나 근거가 약함 | 보류·추가 확인·조건을 연결 |
| 데이터 증거 | 평균만 확인 | 일부 그룹 비교 | 품질감사 후 Tool·Lot·공간 분포 비교 |
| 가설·실험 | 단일 원인 확정 | 가설은 있으나 반증 불명확 | 경쟁 가설·대조군·판정 기준 제시 |
| 자원 판단 | 도구를 많이 선택 | 비용 또는 정보 한쪽만 고려 | 필수 정보영역과 비용·시간을 함께 고려 |
| AI 검증 | 그대로 채택 | 수정·보류만 표시 | 데이터·출처·측정원리로 채택·수정·기각 |
| 산업맥락 | 최신 이슈를 나열 | 지표를 직무와 부분 연결 | 기준일·단위·출처를 확인하고 공정 판단과 연결 |
| SCM 이해 | 회사명만 나열 | 역할 분류 | 고객·Fab·장비·재료 관계와 근거·불확실성을 설명 |

채점자 2명이 독립 채점하고 불일치는 근거를 남겨 합의한다. 가능하면 반도체 교육자 또는 현업 경험자 1명을 포함한다.

## 6. 종료 설문

5점 척도:

1. 시작 방법을 이해하기 쉬웠다.
2. 데이터 화면에서 필요한 정보를 찾을 수 있었다.
3. AI 대화가 가설을 좁히는 데 도움이 됐다.
4. AI 답을 직접 검증해야 한다는 점을 이해했다.
5. 최종 역량 리포트가 내 판단 과정을 설명하는 데 도움이 됐다.
6. 반도체 취업과정에 이 실습이 포함되면 참여할 의향이 있다.
7. 유료 교육과정의 일부로 제공될 가치가 있다고 생각한다.
8. 산업동향·용어·SCM 지도가 공정 문제를 이해하는 데 도움이 됐다.
9. 기업정보의 출처와 기준일을 확인할 수 있어 신뢰가 갔다.

자유응답:

- 가장 도움이 된 순간은 무엇인가.
- 가장 막힌 단계는 무엇인가.
- 기존 반도체 강의와 다른 점은 무엇인가.
- 제거해야 할 기능은 무엇인가.
- 추가하고 싶은 공정 문제는 무엇인가.
- 가장 필요한 기업정보는 제품·공정역할·고객·설비·재료·채용·재무 중 무엇인가.
- 매주 갱신받고 싶은 산업지표 또는 기업 변화는 무엇인가.

- 참여자 5명 이상
- 대표 시나리오 완주율 80% 이상
- 중대한 데이터·세션 손실 0건
- 사전·사후 평균점수와 개인별 변화 공개
- AI 검토 행동 1회 이상 참여자 70% 이상
- 교육과정 재사용 의향 4점 이상 참여자 60% 이상
- 산업·SCM 정보가 공정이해에 도움됐다는 응답 4점 이상 70% 이상
- 기업·산업정보의 출처와 기준일 확인 성공 70% 이상
- 공식 확인 관계와 추론 관계 구분 성공 70% 이상
- 심각한 보안·기밀 입력 0건
