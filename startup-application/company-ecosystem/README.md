# 반도체 생태계 기업 심층분석 시리즈

작성 기준일: 2026-08-23

## 목적

기업을 투자종목 이름으로 외우는 대신 `제품 → 공정 → 고객가치 → 공급망 → 직무 → 가상팹 사건`으로 이해한다. Alpha Hunter는 후보 발굴에 활용하지만, 본 시리즈의 기업 사실은 공시·SEC·기업 IR·공식 제품자료를 다시 확인한다.

## 공통 분석 구조

1. 생태계 위치와 한 문장 정의
2. 핵심 제품과 적용 공정
3. 고객이 구매하는 이유와 KPI
4. 수익모델과 설치기반 서비스
5. 경쟁·대체 가능성·협력사
6. 최신 실적과 기술투자
7. 고객·지역·규제·공급망 위험
8. 현업 용어와 채용 직무
9. 가상팹 시나리오 연결
10. 공식 사실·해석·추론 구분

## 데이터 표시 규칙

- `공식 사실`: 공시·SEC·기업 공식자료에서 직접 확인
- `계산`: 공식 수치로 독립 계산
- `해석`: 공식 사실의 교육적 의미
- `추론`: 추가 검증이 필요한 연결
- 고객사 이름과 공급관계는 공식 공개 근거가 있을 때만 확정한다.
- 시장점유율·목표가격·매수추천은 Industry Twin 데이터에 넣지 않는다.
