## 사용 순서

1. 주관기관에서 기창업자 이종창업·재직자 참여 조건을 서면 확인한다.
2. 렛유인 담당자의 사전 승인을 받아 자율 참여자 5–10명을 모집한다.
3. 파일럿 프로토콜에 따라 익명 사전·사후 검증을 진행한다.
4. 표본 수·이탈·실패를 포함한 결과보고서를 작성한다.
5. 실제 검증 결과를 공식 신청서 문항과 글자 수에 맞춰 반영한다.

현재 문서는 공식 제출본이 아니다. 고객 인터뷰·파일럿 원자료와 공식 신청양식을 반영한 뒤 최종화한다.
