## 사용 순서

1. 주관기관에서 기술특화 트랙, 기창업자 이종창업·재직자 참여 조건을 서면 확인한다.
2. 렛유인 담당자의 사전 승인을 받아 자율 참여자 5–10명을 모집한다.
3. 학생에게 산업동향·현업 용어·SCM·기업정보의 우선순위를 먼저 묻는다.
4. 파일럿 프로토콜에 따라 Industry Twin 개념검증과 가상팹 사전·사후 검증을 진행한다.
5. 표본 수·이탈·실패를 포함한 결과보고서를 작성한다.
6. 실제 검증 결과를 공식 신청서 문항과 글자 수에 맞춰 반영한다.

현재 정본은 공고와 구현상태를 반영한 **제출 준비본**이다. 플랫폼의 실제 문항 글자 수, 기창업자 이종창업 자격에 대한 운영기관 답변, 신청자의 비공개 증빙정보와 파일럿 원자료는 신청자가 직접 확인·입력한다.
