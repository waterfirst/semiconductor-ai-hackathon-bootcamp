# FAB-JUDGMENT Industry Twin · 산업데이터 계층 설계

작성일: 2026-08-23
상태: 정부지원사업 신청 및 학생 개념검증용 설계 초안

## 1. 제품 역할

Industry Twin은 산업정보 포털을 하나 더 만드는 기능이 아니다. 학생이 산업동향·현업 용어·SCM 기업역할을 먼저 이해하고, 그 지식을 가상팹 사건의 원인 가설·DOE·조치 판단에 실제로 사용하게 만드는 근거 계층이다.

핵심 흐름:

`산업동향 확인 → 용어·SCM 관계 이해 → 가상팹 사건 분석 → AI 반론·검증 → 역량 증거·면접 PT`

## 2. 학생에게 보여줄 정보

### 산업동향

- 반도체와 반도체 제조용 장비의 수입 변화부터 시작하고, 검증된 수출 원천을 확보한 뒤 범위를 확장
- 기준일, 집계기간, 단위, 잠정치 여부
- 변화가 직무와 공급망에 줄 수 있는 영향은 `해석`으로 분리

### 현업 용어

- 공정: PHOTO, ETCH, CVD, CMP, DIFFUSION, IMPLANT, METROLOGY
- 데이터: CD, uniformity, edge, lot, wafer, slot, recipe, SPC, DOE, holdout
- 공급망: Fabless, IDM, Foundry, Fab, OSAT, 장비, 재료, 고객
- 각 용어를 정의·관련 직무·관련 기업역할·시나리오 증거와 연결

### SCM 기업지도

- 설계/IP → Fabless/IDM → Foundry/Fab → 장비·재료 → OSAT/Test → 고객
- 회사별 공식 사업영역, 대표 제품군, 최근 공시와 기준일
- 특정 고객·공급사 연결은 공식 공개 근거가 있을 때만 확정 표시

## 3. 데이터 신뢰 모델

모든 사실과 관계에는 다음 중 하나의 등급을 부여한다.

- `official_disclosure`: 회사 공시·정부 원자료에서 직접 확인
- `official_announcement`: 회사·기관 공식 발표에서 확인
- `public_classification`: 제품·업종·NCS 등 공개 분류에 따른 역할 배치
- `curated`: 교육전문가가 출처를 검토해 구성
- `inferred`: 공개 사실을 바탕으로 한 추론이며 사실로 단정하지 않음

필수 메타데이터:

```text
source_name
source_url
effective_date
fetched_at
schema_version
confidence
review_status
```

## 4. 공식 원천 후보

1. [금융감독원 OpenDART](https://opendart.fss.or.kr/guide/main.do): 기업개황·공시검색·정기보고서·재무정보
2. [관세청 공공데이터](https://www.data.go.kr/data/15157901/openapi.do): 반도체·반도체 제조용 장비의 10일 단위 잠정 수입통계
3. [NCS 공공데이터](https://www.data.go.kr/dataset/3072161/openapi.do?lang=ko): 직무·능력단위·훈련정보
4. [KOSHA 공공데이터](https://www.data.go.kr/data/15121001/openapi.do): 제조업 사고 사례와 안전 맥락
5. [KIPRIS Plus](https://plus.kipris.or.kr/portal/data/apiEnter/List.do?pageIndex=1): 특허·기술동향의 선택적 보강

KIPRIS는 무료 호출 한도 이후 비용이 발생할 수 있으므로 1차 MVP의 필수 의존성으로 두지 않는다. 외부 API의 이전·중단·스키마 변경에 대비해 검증된 원자료 스냅샷과 계약시험을 유지한다.

## 5. 시스템 모듈

1. **Data Gateway:** 키를 서버에 보관하고 원천별 호출·캐시·오류를 통합한다.
2. **Normalizer:** 회사·제품·공정·직무·용어·지표를 공통 스키마로 변환한다.
3. **Knowledge Graph:** 엔터티 관계와 출처·신뢰등급을 함께 저장한다.
4. **Scenario Composer:** 산업 사건을 가상팹의 공정 이상·제약조건과 연결한다.
5. **Evidence RAG:** AI가 허용된 근거만 인용하고 출처 없는 기업 사실을 생성하지 못하게 한다.
6. **Competency Engine:** 학생이 근거를 찾고 사실·추론을 구분해 판단에 썼는지 평가한다.

## 6. Alpha Hunter 기업발굴 연계

Alpha Hunter는 후보를 찾는 내부 리서치 도구로만 사용하고, 학생 화면이나 평가엔진이 투자판단 값을 직접 읽지 않도록 분리한다.

### 입력 허용

- 기업 식별자와 국가·시장
- 공식 공시·IR·SEC 원문 URL
- 공식 사업부문·제품군·매출구성 후보
- 관련 공정·장비·재료·경쟁사 후보
- 조사 기준일과 원자료 발행일

### 입력 금지

- SEPA·모멘텀·밸류에이션 점수
- 목표주가·손절가·매수·매도 의견
- 모의·실제 포트폴리오와 계좌정보
- 출처가 불명확한 시장점유율·고객관계·전망치

### Evidence Gate

1. Alpha Hunter가 반도체 기업 후보와 확인할 주장 목록을 보낸다.
2. Data Gateway가 DART·SEC·기업 IR 등 1차 원문을 다시 수집한다.
3. 출처·기준일·인용 위치가 없는 주장은 탈락시킨다.
4. 교육전문가가 SCM 역할과 공정 연결을 검토한다.
5. 승인된 사실과 명시적 추론만 Knowledge Graph에 게시한다.

두 저장소는 보고서 파일을 서로 직접 읽지 않고, 검증된 필드만 담은 버전형 JSON 계약으로 교환한다. 이렇게 해야 투자용 문장과 교육용 사실이 섞이지 않는다.

## 7. 1차 MVP 범위

- 산업지표 카드 3개
- 현업 용어 30개
- SCM 역할 8개
- 공개 기업 프로필 20개
- PHOTO 대표 사건 1개와 산업·SCM 맥락 연결
- 모든 카드에 출처·기준일·신뢰등급 표시
- 학생이 기업 3개를 SCM에 배치하고 근거를 제출하는 미니 과제

실시간 자동갱신보다 정확한 스냅샷과 출처 표시를 먼저 완성한다.

## 8. 금지사항

- 비공개 고객명·공급조건·공정 Recipe 추정
- 공시되지 않은 거래관계를 확정 사실로 표시
- 출처 없는 AI 요약을 기업 프로필에 저장
- 잠정 통계를 확정치처럼 표시
- API 키를 브라우저·Git 저장소·다운로드 파일에 포함
- 실제 기업 내부자료를 학생에게 업로드하도록 요구

## 9. 검증 기준

- 원문 링크 도달률 100%
- 카드의 기준일·단위·잠정치 표기 누락 0건
- 공식 사실과 추론의 UI 구분 100%
- 동일 스냅샷과 시나리오 버전에서 결과 재현
- API 장애 중에도 검증 스냅샷으로 수업 완주
- 학생 70% 이상이 출처·기준일과 공식 사실·추론을 구분

## 10. 신청서 핵심 문장

> FAB-JUDGMENT Industry Twin은 공개 산업데이터를 나열하는 정보서비스가 아니라, 출처·기준시점·신뢰등급이 보존된 반도체 지식그래프를 합성 공정 시뮬레이션과 연결하고, 학생이 AI의 제안을 검증하며 내린 판단을 역량 증거로 변환하는 기술특화 교육 SaaS다.
