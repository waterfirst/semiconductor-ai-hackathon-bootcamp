# 반도체·디스플레이 산업 지식맵 지역 확장 조사

기준일: 2026-08-23
적용 화면: <https://waterfirst.pro/virtual-fab/#industry-map>

## 조사 목적

기존 미국·일본 중심의 기업 지식맵을 대한민국·중국·미국·유럽의 실제 반도체·디스플레이 밸류체인으로 확장한다. 학생이 회사 이름을 외우는 데서 끝나지 않고 **제품 → 공정 → 직무 → 산업 위험**을 한 화면에서 탐색하도록 만드는 것이 목적이다.

## 선정 원칙

1. 반도체 또는 디스플레이의 설계·소재·장비·제조·패키징에 직접 참여하는 기업만 포함했다.
2. 기업 홈페이지, 연차보고서, SEC 공시 등 1차 자료로 역할과 제품을 확인했다.
3. 두 회사 사이 선은 당사자 공식자료나 규제기관 공시로 확인된 경우만 추가했다.
4. 비공개 거래액·시장점유율·공급 비중은 추정하지 않았다.
5. 공식자료가 과거 시점의 공급관계를 서술하면 그 기준일을 그대로 표시하고 현재 관계로 단정하지 않았다.

## 화면 반영 결과

- 기업 노드: **38개 → 58개**
- 국가·지역 필터: **대한민국 / 중국 / 미국 / 유럽 / 일본·대만**
- 산업 필터: 반도체 / 디스플레이 / 공통 기술
- 공식 관계선: **15개 → 23개**
