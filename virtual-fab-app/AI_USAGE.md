# AI Usage

## 사용 범위

- 시나리오 흐름, 단계별 React/Three.js 장면, FastAPI 상태 전이, DeepSeek API 및 외부 AI 질문·답변 기록 흐름, Base64 HTML 슬라이드, 테스트 및 문서 초안에 AI를 활용했다.
- 최종 실행 결과는 Python API 테스트, TypeScript 빌드, Playwright 데스크톱·모바일 테스트로 검증했다.
- 시나리오 버전·seed·판단 순번을 세션과 Evidence trail에 기록하는 재현성 설계 및 테스트 초안에 AI를 활용했다.
- 사용자 제공 데스크톱 화면을 근거로 입실 안내 카드 안전영역과 상단 단계 레일 가독성을 조정하고, Playwright 회귀 검사를 추가하는 데 AI를 활용했다.
- OpenAI·Gemini·Anthropic·DeepSeek 개인 API 연결, 비밀키 비저장, HTTPS 강제, 호출 제한과 제공사별 응답 정규화 코드 및 보안 테스트 초안에 AI를 활용했다.
- 2026-08-17 PHOTO seed별 합성데이터 연동, 비공개 정답키 채점, 서버 Holdout, `radius_mm` bin 집계 UI와 회귀 테스트 구현에 AI를 활용했다. 사용자가 입력하는 검증 수치와 42행 하드코딩을 제거했으며, 생성기·정답키·API 결과를 테스트로 대조했다.
- 2026-08-22 분석 도구의 교육용 정보가치, 필수 정보영역 충족도, 예상 증거 신뢰도와 최소 자원 완전조합 비교 규칙 및 UI·회귀 테스트 구현에 AI를 활용했다. 실제 측정 정확도나 인과 확률이 아님을 화면과 README에 명시했다.
- 2026-08-23 기존 서버 판단 기록을 5개 문제해결 역량과 AI 사람 검토 수로 재구성하는 역량 증거 리포트, API·최종 Markdown·반응형 UI·회귀 테스트 초안에 AI를 활용했다. 사전·사후 실증 전에는 학습 향상으로 표현하지 않도록 제한 문구를 함께 구현했다.
- 2026-08-23 반도체 생태계 28개 회사의 3D 노드·공정 연결·상세 패널 초안에 AI를 활용했다. 회사 간 선은 실제 거래관계가 아닌 교육용 공정 역할 분류라고 고지했으며, ASML·Applied Materials는 공식 실적과 공시를 출처로 수치를 재계산했다. 나머지는 공식 홈페이지 기반 요약 프로필로 구분하고 검증되지 않은 실적·점유율을 표시하지 않았다.

## 사람의 검증 책임

- 공정 용어와 학습 목표는 강사가 검토한다.
- 시나리오의 수치와 판정 규칙은 교육용이며 실제 Recipe 또는 Spec으로 전용하지 않는다.
- LLM 제안은 정답으로 처리하지 않고 경쟁 가설·반증 가능성·누락 변수를 검토한다.
- DeepSeek 또는 외부 AI의 모델명·질문·답변과 사람의 수정·검증 판단을 함께 기록하며, AI 출력만으로 공정 결론을 확정하지 않는다.
- 공개 전 실제 회사정보, 개인정보, API 키가 포함되지 않았는지 확인한다.
